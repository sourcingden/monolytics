# Monolytics

Чесна аналітика витрат із CSV-виписки Монобанку. Категоризація, реальна картина
витрат (без переказів і кредитів, які Монобанк рахує "тратами"), 18 автоматичних
інсайтів, бюджет 50/30/20, симулятор "а що якщо" — все у браузері, без бекенду.

## Приватність

Це статичний застосунок. CSV читається, обробляється і зберігається **виключно
в браузері** (IndexedDB) — жодних серверів, жодних зовнішніх викликів, жодного
AI. Перевірити це можна за один погляд у мережеву вкладку інструментів
розробника під час роботи з даними, або в `package.json` — там немає жодного
мережевого SDK. Деталі архітектурного рішення — у плані розробки.

## Розробка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest, src/core/** — вся бізнес-логіка
npm run lint        # oxlint
npm run build       # tsc -b && vite build → dist/
```

Спробувати без своєї виписки: кнопка "Спробувати на демо-даних" на екрані
завантаження — вона показує синтетичний, повністю вигаданий набір даних
(`src/assets/demo-statement.csv`), що відтворює всі структурні патерни реальної
виписки Монобанку без жодних реальних персональних даних.

## Структура

- `src/core/` — уся бізнес-логіка: парсер CSV, каскад категоризації, аналітика,
  18 детекторів інсайтів, бюджетні розрахунки. Чистий TypeScript, без React і
  без DOM — див. `src/core/README.md`.
- `src/store/` — zustand-стор + персистентність через IndexedDB (`idb-keyval`).
- `src/i18n/` — словники UA/EN.
- `src/ui/` — React-екрани та компоненти.
- `data/` — `mcc.json` (таблиця MCC-кодів) і `merchants.ua.json` (словник
  українських мерчантів) — найважливіший файл для розширення без AI-підстраховки.
- `tests/fixtures/` + `scripts/generate-fixture.mjs` — синтетична фікстура для
  тестів, що відтворює реальні структурні патерни виписки.

## Деплой

`.github/workflows/deploy.yml` збирає та публікує `dist/` на GitHub Pages при
push у `main`. Базовий шлях налаштовано на `/monolytics/` у `vite.config.ts` —
зміни, якщо назва репозиторію інша.
